# Lock In TIme tracker

The goals and core foundations (and also usp) of this app is

1. Minimal and sleek ui, no fluff or anything. Just pure execution and analysis of focus times.
2. Cross platform friendly.
3. on mobile, can be installed from chrome using install option in chrome options
4. Light and dark theme
5. IOS inspired ui
6. Stopwatch, focus timer (can be set to max 3 hrs countdown)
7. Countdown doesnt stop in background, help user configure it based on browser detected (or mobile browser)
8. Supports live notification (through browser), which can be crossed or cut easily.

9. Notification has pause or resume option (this also gets recorded, paused for how much time in timeline analysis)
10. Ability to choose tag for a timer (and tag colors)
11. Overall minimal, clean ui, no fluffy elements.
